## Inkspect code review

Pull requests use the **Inkspect Code Review** workflow. Its
**Request Inkspect Cloud Engine** step sends a review request without repository
token permissions, secrets, or a checkout. The first request waits for approval
in Tokyo. A successful workflow means the request was received; review findings
are published separately after repository approval and successful project CI.

The workflow currently expects a separate CI workflow named `CI`. This repository
does not yet contain that workflow; add project CI before enabling reviews.
